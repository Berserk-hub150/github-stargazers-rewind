# Security Policy

## Reporting a vulnerability

Do not publish credentials, private data, or exploitable security details in a public issue.

When reporting a security concern, include:

- the affected file or component;
- the security impact;
- reproducible steps using non-sensitive test data;
- a suggested mitigation, if known.

## Scope

This extension does not require a GitHub personal access token. Any change that introduces authentication, additional host permissions, remote code execution, or new third-party data destinations should receive additional review.
